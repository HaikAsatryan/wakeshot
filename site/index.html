Wakeshot

Your PC stays awake while your AI agent works. Then it sleeps as usual, with your own power settings back.

Keep awake on demand comes in the same menu, so you never need a second tool.

What keeps the PC awake

Wakeshot calls each reason to stay awake a hold. While any hold counts, the PC stays awake. When the last one ends, the PC sleeps as usual, as if Wakeshot were not there.

Claude Code

Wakeshot reads the small status file Claude Code keeps for each session. A session holds while it works, also while its background tasks run. No hooks, no edits to Claude's settings, and your prompts are never stored or logged.

wakeshot run

Put it before any long command: a build, a test suite, a backup. Such as wakeshot run -- npm test. The PC stays awake until the command ends, and the command keeps its exit code.

Hold files

Any script can hold the PC awake by writing a small JSON file. The hold lasts while the process named in it runs. The format.

Keep awake

From the menu: 30 minutes, 1, 2 or 4 hours, or until you turn it off, with Keep screen on if you want it. It ends at sign-out or restart, so a forgotten one never survives a reboot.

The tray icon shows the state: the sun is up while something holds, an empty sun when nothing does, and the empty sun struck through when Automatic is off. Its tooltip names what holds the PC awake, such as "Holding awake: Claude Code (1 session)".

Claude Code is the agent Wakeshot knows in v1. Codex CLI and Copilot CLI come next. Until then, wakeshot run -- <agent> holds for as long as the agent runs.

A night with Wakeshot

  1. You give Claude Code a long task and walk away. The icon shows the sun up. Your screen still turns off on its usual timer; only sleep waits.
  2. You close the lid. A short chime says the laptop keeps running, and Wakeshot locks it, so a closed laptop never runs unlocked.
  3. Claude finishes in the night. Wakeshot puts your lid and sleep settings back at once. After 5 minutes with no input, a soft "going to sleep" sound plays and the laptop goes to sleep, where Windows would have put it when you closed the lid.
  4. Morning. You open the lid and sign in. A notice says how long the PC ran with the lid closed, and what kept it running.
  5. The battery ran low instead? Below Windows' own energy saver level, Wakeshot steps back and puts your settings back. A closed laptop then goes to sleep after 5 minutes with no input.

What it changes on your PC

When nothing holds, Wakeshot changes nothing. While something holds, it asks Windows to keep the system running, and changes three settings of your active power plan:

SettingWhile holdingWhy
Lid close, plugged inDo nothingNo power request can stop a lid close; only this setting keeps a closed laptop working
Lid close, on batteryDo nothingThe same
Sleep after, on batteryNeverOn battery, Windows ends every power request about 5 minutes after this timeout
  • Your own values come back when the work ends, at Quit, at sign-out, at the next start and at uninstall. If Wakeshot crashes, a small guard process puts them back.
  • Change one of these settings yourself during a hold, and your change wins at once. Restore my power settings in the menu puts them back right away.
  • Wakeshot never lowers your security: close the lid while something holds, and it locks the PC.
  • It never needs admin rights and never touches other apps.

Every detail, and the rare cases where your settings stay changed for a while, are in the README.

Install

  1. Download the Setup for your PC from Releases:
    • most PCs: HaikAsatryan.Wakeshot-win-x64-Setup.exe
    • Windows on Arm: HaikAsatryan.Wakeshot-win-arm64-Setup.exe
  2. Run it. It installs for your user only and never asks for admin rights. Wakeshot starts right away, and from then on at each sign-in.
  3. Its icon may hide under the ^ arrow on the taskbar. The first notice says how to keep it in view.

Not signed yet. v1 is not code-signed, so Windows SmartScreen may warn you before Setup runs.

Updates. Wakeshot updates itself from GitHub Releases, and only while nothing holds, so an update never cuts your work short.

Uninstall from Settings > Apps, like any app. It puts your power settings back if a hold was running.

Privacy

  • No telemetry and no account.
  • The only network calls are the update checks and downloads, to GitHub.
  • The log stays on your PC. It never holds your prompts, transcript text or full command lines.
  • This page has no scripts and no trackers, and loads nothing from other sites. GitHub Pages, which hosts it, logs each visitor's IP address for security, as GitHub's own docs say.
