# Title: what the task does

Phase: N. Status: ready | in progress | blocked | done. Needs Haik: no | yes (what, when).
Runs after: cards that must finish first, or "none". Parallel with: cards that may run at the same time.

## Goal

One or two sentences.

## Read first

Files and sections, nothing more.

## Deliverables

Files to create or change.

## Acceptance checks

Checks the worker runs and records. Each one passes or fails.

## Out of scope

What not to touch.

## Questions for Haik

Each with the worker's default.

## Found outside scope

Problems seen but not fixed.

## Log

- YYYY-MM-DD: short line.

## Result

What was done, files changed, checks and outcomes, open items.
